TRAIN ROBOMIMIC BC
==================

python scripts/robomimic/train.py \
    --task Agibot-Toy2Box-RmpFlow-v0 \
    --algo bc \
    --epochs 2000 \
    --seed 101 \
    --dataset ./datasets/toy2box_generated.hdf5 \
    --norm False \
    --output_dir ./output/gen_

# 저장: <output_dir>/model_epoch_XXXX.pth, config.json, log.txt, tb/
# 학습 seed: --seed 111 등으로 변경. 생략하면 JSON의 train.seed 사용(기본 101).
# resume는 저장된 seed와 RNG 상태를 유지. 다른 --seed는 새 학습에서 지정.
# --output_dir ./output/bc_run 이면 ./output/bc_run 바로 아래 저장. --name은 로그 표시용 이름.
# BC-RNN 기본 obs: 기존 19차원 + eef_to_toy_distance(1) + grasp_rotation_error(1) = 21차원.
# joint_pos / joint_vel / box_orientations / 기존 eef_to_toy(3)는 제외.
# 거리 단위 m, 회전 오차 단위 rad. 기존 HDF5로 계산하므로 재수집 불필요.
# 파지 회전 기준은 선택된 학습 데모의 첫 들어 올림 자세에서 추정하고 체크포인트에 저장.
# play/resume은 저장된 기준을 그대로 복원. 기준 자세 추정에 쓸 데모가 없으면 오류로 중단.
# 관측 정규화: --norm True / False. 기본 False.
# True면 학습 데이터 mean/std로 정규화하고 체크포인트에 통계 저장. play에서 자동 적용.
# 21차원 입력은 --resume 없이 새 output_dir로 학습. 기존 체크포인트의 관측 구성은 유지.

# 1000 epoch 체크포인트에서 1001~2000 epoch 추가 학습
python scripts/robomimic/train.py \
    --resume /ABSOLUTE/PATH/TO/model_epoch_1000.pth \
    --epochs 2000

# --task / --algo 생략 가능. 관측 구성·학습 설정은 체크포인트에서 복원.
# 기본 저장 위치는 체크포인트가 있는 폴더. --output_dir 지정 시 항상 그 폴더 바로 아래 저장.
# config.json과 같은 이름의 모델은 덮어쓰고 log.txt / TensorBoard는 이어 기록.
# 실험명·timestamp·models·logs 중간 폴더 생성 없음.
# 예전 models/logs 구조의 체크포인트는 --output_dir 생략 시 기존 위치를 유지.
# 데이터 위치가 바뀌었으면 --dataset /PATH/TO/SAME_DATASET.hdf5 추가.
# 기존 체크포인트는 가중치만 복원하며 optimizer / LR scheduler는 새로 시작.
# 이후 저장본은 epoch / optimizer / LR scheduler / RNG 상태도 저장·복원.
# --epochs는 최종 epoch. 1000 -> 2000은 1000 epoch 추가 수행.
# 기존 23·91·94차원 체크포인트를 resume하면 해당 관측·정규화 구성을 유지.
# resume 중 --norm으로 정규화 설정을 바꾸면 오류. 변경은 새 학습에서 선택.
# action 정규화를 사용했다면 동일한 정규화 데이터셋 사용. resume 시 --normalize_training_actions 생략.


PLAY A CHECKPOINT
=================

python scripts/robomimic/play.py \
    --task Agibot-Toy2Box-RmpFlow-v0 \
    --device cuda \
    --seed 42 \
    --num_rollouts 100 \
    --checkpoint /ABSOLUTE/PATH/TO/model_epoch_XXXX.pth

# --seed 기본값 101. --seed와 --seeds 중 하나만 지정.
# seed별 환경을 새로 생성하며 생성 전부터 seed 적용. 학습 seed와 평가 seed는 별개.
# 결과: seed별 성공 횟수·성공률·True/False 목록, seed 간 성공률 평균·표준편차(ddof=0).
# seed가 하나면 seed 간 표준편차는 0. 에피소드 길이는 전체 rollout의 평균·표준편차(step) 출력.

# IsaacLab_RS robomimic play와 같은 rollout별 영상 저장: 체크포인트의 obs 차원 자동 선택
python scripts/robomimic/play.py \
    --task Agibot-Toy2Box-RmpFlow-v0 \
    --checkpoint ./output/bc_choi_gen_26/model_epoch_2000.pth \
    --device cuda \
    --seed 42 \
    --num_rollouts 100 \
    --horizon 800 \
    --video \
    --video_length 1000 \
    --video_folder ./videos/bc_choi_gen_26 \
    --headless

# --video 기본 비활성. --video_length 기본 800 step. --real-time으로 실시간 재생 속도에 맞춤.
# 기본 저장: ./videos/robomimic/<모델명>-seed-<seed>-episode-<trial>.mp4
# --video_folder로 저장 폴더 지정. 기존 --video_dir도 같은 옵션. 폴더는 자동 생성.
# 영상 파일은 지정한 폴더 바로 아래 저장.
# Viewer 카메라 하나를 녹화하며 --video가 렌더링을 자동 활성화. 학습에 카메라 obs를 쓸 필요 없음.
# rollout마다 별도 영상 저장. --num_rollouts 100이면 seed당 영상 100개.
# rollout 종료 시 저장하며 --video_length는 각 영상 최대 길이. 평가 horizon과 별개.
# headless에서도 reset 시작·완료, 100 step마다 진행률, MP4 인코딩 시작·완료 로그 출력.
# 모델 로더는 BC-RNN 전용. 현재 학습 JSON 대신 체크포인트의 obs/정규화 설정을 사용.
# 파생 obs는 해당 모델이 요구할 때만 계산. 19/21/23/26/91/94차원을 고르는 옵션은 필요 없음.
