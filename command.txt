TRAIN ROBOMIMIC BC
==================

python scripts/robomimic/train.py \
    --task Agibot-Toy2Box-RmpFlow-v0 \
    --algo bc \
    --epochs 2000 \
    --dataset ./datasets/toy2box_generated.hdf5 \
    --norm False \
    --output_dir ./output/gen_

# 저장: <output_dir>/model_epoch_XXXX.pth, config.json, log.txt, tb/
# --output_dir ./output/bc_run 이면 ./output/bc_run 바로 아래 저장. --name은 로그 표시용 이름.
# BC-RNN / ACT 기본 obs: EEF·그리퍼·장난감·상자 23차원. joint_pos / joint_vel / eef_to_toy 제외.
# 관측 정규화: 두 모델 모두 --norm True / False. 기본 False.
# True면 학습 데이터 mean/std로 정규화하고 체크포인트에 통계 저장. play에서 자동 적용.
# 23차원 입력은 --resume 없이 새로 학습. 기존 체크포인트의 관측 구성은 유지.

# 1000 epoch 체크포인트에서 1001~2000 epoch 추가 학습
python scripts/robomimic/train.py \
    --resume /ABSOLUTE/PATH/TO/model_epoch_1000.pth \
    --epochs 2000

# --task / --algo 생략 가능. 관측 구성·학습 설정은 체크포인트에서 복원.
# 기본 저장 위치는 체크포인트가 있는 폴더. --output_dir 지정 시 항상 그 폴더 바로 아래 저장.
# config.json과 같은 이름의 모델은 덮어쓰고 log.txt / TensorBoard는 이어 기록.
# 실험명·timestamp·models·logs 중간 폴더 생성 없음.
# 예전 models/logs 구조의 체크포인트는 --output_dir 생략 시 기존 위치를 유지.
# 데이터 위치가 바뀌었으면 --dataset /PATH/TO/SAME_DATASET.hdf5 추가.
# 기존 체크포인트는 가중치만 복원하며 optimizer / LR scheduler는 새로 시작.
# 이후 저장본은 epoch / optimizer / LR scheduler / RNG 상태도 저장·복원.
# --epochs는 최종 epoch. 1000 -> 2000은 1000 epoch 추가 수행.
# 기존 23·91·94차원 체크포인트를 resume하면 해당 관측·정규화 구성을 유지.
# resume 중 --norm으로 정규화 설정을 바꾸면 오류. 변경은 새 학습에서 선택.
# action 정규화를 사용했다면 동일한 정규화 데이터셋 사용. resume 시 --normalize_training_actions 생략.


PLAY A CHECKPOINT
=================

python scripts/robomimic/play.py \
    --task Agibot-Toy2Box-RmpFlow-v0 \
    --device cuda \
    --seed 101 \
    --num_rollouts 20 \
    --checkpoint /ABSOLUTE/PATH/TO/model_epoch_XXXX.pth

# 여러 seed의 성공률 평균·표준편차 평가: seed당 50회, 아래 예시는 총 150회
python scripts/robomimic/play.py \
    --task Agibot-Toy2Box-RmpFlow-v0 \
    --device cuda \
    --headless \
    --seeds 101 102 103 \
    --num_rollouts 50 \
    --checkpoint ./output/bc_choi_gen_23/model_epoch_2000.pth

# --seed 기본값 101. --seed와 --seeds 중 하나만 지정.
# seed별 환경을 새로 생성하며 생성 전부터 seed 적용. 학습 seed와 평가 seed는 별개.
# 결과: seed별 성공 횟수·성공률·True/False 목록, seed 간 성공률 평균·표준편차(ddof=0).
# seed가 하나면 seed 간 표준편차는 0. 에피소드 길이는 전체 rollout의 평균·표준편차(step) 출력.


TRAIN ACT
==========

# IsaacLab conda 환경에서 최초 한 번 (카메라 사용 시 호환되는 torch/torchvision 필요)
python -m pip install -e '.[act]'

# 카메라 없이 학습: 이미지 데이터/인코더/임베딩을 사용하지 않음
python scripts/act/train.py \
    --dataset ./datasets/toy2box_raw.hdf5 \
    --enable_cam False \
    --norm False \
    --action_chunk 10 \
    --seed 101 \
    --steps 100000 \
    --log_freq 100 \
    --output_dir ./output/act_state

# RGB를 수집한 데이터셋으로 세 카메라 학습
python scripts/act/train.py \
    --dataset ./datasets/toy2box_rgb.hdf5 \
    --enable_cam True \
    --cameras eye top front \
    --action_chunk 10 \
    --output_dir ./output/act_camera

# --cameras는 eye/top/front 중 1~3개 지원. 생략하면 HDF5 RGB 관측 키를 자동 탐색.
# 새 학습은 temporal ensemble 계수 0.01, n_action_steps=1이 기본
# 끄기: --temporal_ensemble_coeff None (이때 n_action_steps 기본값은 action_chunk)
# 관측 정규화는 BC-RNN과 같은 옵션: --norm True / False (기본 False)
# action 정규화는 별도 옵션: --normalize_training_actions
# --batch_size 100, --num_workers 4가 현재 기본값. --use_amp True로 원본의 선택적 AMP 활성화
# 새 ACT 학습은 성공한 BC-RNN과 같은 obs 23차원 (EEF/그리퍼/장난감/상자), 관절 위치·속도 제외
# 기존 obs 91차원 체크포인트는 --resume/play에서 기존 관측을 유지. obs 23차원은 새 output_dir로 새 학습
# 기본 --steps 100000. 이전 --epoch/--epochs 대신 --steps 사용
# 평균 지표: <output_dir>/metrics.csv (--log_freq 200 step마다 + 마지막)
# 체크포인트: model_step_1000.pt, model_step_2000.pt, ... (--save_freq 1000 step마다 + 마지막)
# latest.pt는 체크포인트 저장 시 갱신

# 60,000 step 체크포인트에서 총 100,000 step까지 재개 (추가 40,000 step)
# 데이터/모델/학습 설정 자동 복원. 기록은 원본 폴더 아래 resume_step_60000에 저장
python scripts/act/train.py \
    --resume ./output/act_base_gen_steps/model_step_60000.pt \
    --steps 100000
